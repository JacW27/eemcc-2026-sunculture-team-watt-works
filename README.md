# 2026 EEMCC — SunCulture Round 1

This repository contains the research, strategic analysis, quantitative modeling, and supporting materials developed for the 2026 Energy in Emerging Markets Case Competition Round 1.

The analysis focuses on two core questions:

1. **What makes SunCulture valuable — and to whom?**
2. **Where should SunCulture's next phase of growth come from?**

Supporting quantitative work evaluates farmer affordability, repayment capacity, and PAYGrow economics.
